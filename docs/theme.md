# Thème global

Direction : sombre, indigo/violet, d'après une image de référence (couleurs mesurées sur l'image, non redistribuée).

## Schéma de couleurs DistroNight
- Dérivé de BreezeDark.colors (KDE, LGPL-2.0-or-later), palette modifiée
- Fichier : src/includes.chroot_after_packages/usr/share/color-schemes/DistroNight.colors
- Mesurées : #1a192f #0f1024 #282641 #544c6f #998aa9 #473d58 #131834
- Proposées (à ajuster à l'écran) : texte #e6e1f2, accent #7a6ad8, avertissement #e8b35c, lien #8ea0f8

## Activation par défaut
- defaults du thème org.kde.breeze.desktop : ColorScheme=DistroNight, icônes breeze-dark
- Autres éléments (style, curseurs, décoration, écran de démarrage) : Breeze inchangés
